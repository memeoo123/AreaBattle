# Recovered arrows, drag preview and cut trail

Source manifest: `gesture-visual-runtime.json`; evidence: `gesture-visual-evidence.json`. Scope is exactly these three visual systems. Original target code is never executed.

1. Call `RecoveredWayLineImporter.Import()` before `RecoveredGestureImporter.Import()`. Merge `RecoveredGestureImporter.Run()` into unified validation (seven checks).
2. Put `RecoveredGestureVisuals` on an identity transform under the battlefield visual root. Use `ResolvePreview(sourceGO,groundPoint,isTower,directRayHitGO)` for the original physics-only preview decision: the closest collider along the entire drag segment can snap a tower even on empty ground; existing line state does not change validity. Its `MoveCut` argument uses that parent's local coordinates, matching original `localPosition`.
3. During line drag call `DrawPreview(sourcePosition,pointerPosition,playerLineColor,valid,targetTransform,expandTaggedTarget,visualTime)`. `valid` is the existing interaction decision; this helper does not invent hit testing or connection rules. Production mouse input and editor replay now share BattleView.BeginTowerDrag, MoveTowerDrag and EndTowerDrag. Release submits the cached target from the last move, exactly as f14746; no mouse-up raycast overwrites it. If valid with a target, the helper replaces the endpoint with the actual target transform position. Ring color is a separate recovered constant; pass source CampConfig.LineColor for the line. `expandTaggedTarget` specifically represents original `LevelControl.IsBossLv && target Tag2`; IsBossLv is verified as presence of StarInfo.isBoss. Boss.Init @0x14ad873..0x14ad89e explicitly sets Tag2 on its model; production adapter therefore maps actual TowerState.IsBoss to this predicate.
4. For cut motion call `MoveCut(point,true)` and on pointer end/cancel call `EndGesture()`. This reproduces immediate hide and native trail lifetime; do not independently draw a debug segment over it.
5. After projectile state advancement call `SynchronizeArrows(sim.Arrows)`. It follows source ArrowState.Position and release timing, uses native SphereTrails prefab, scale0.5 and euler(0,90,0); original five initially inactive children are selected by child index==source LaunchCamp (no clamping); damage remains exclusively in simulation.
6. Call `Tick(scaledDelta)` once per production `AdvanceFrame` after state synchronization. PS are paused to avoid Unity auto-update plus manual double time. Pass Unity scaled time even when simulation state has stopped, as the original particles/tweens use Unity scaled clock. Cut TrailRenderer retains Unity's own time; standalone editor stepping without engine updates cannot assert its temporal mesh pixels.
7. Call `ResetVisuals()` when restarting/replacing the simulation so reused Arrow IDs cannot retain old objects. Destroying the battlefield visual host also releases children.

All three prefabs preserve native component data, full gradients and animation curves, six PS/renderers, one TrailRenderer, three original materials/textures and original Sphere native mesh. The manifest includes source bundle SHA256 for every native component and exported-file SHA256 for dependencies. Do not infer original-frame visual acceptance from import or formula checks.
